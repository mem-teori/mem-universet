# M.E.M. Universet

Et interaktivt atlas over mulige virkeligheder. Besøgende træder gennem en Yggdrasil-inspireret port og udforsker relationer, perspektiver, manifestationer, resultater og afgrænsninger.

Projektet udgives automatisk fra `main` via GitHub Pages.


## Languages

The site is bilingual. Danish remains at `/`; English is available at `/en/`. A `DA | EN` switch is shown on both versions.
